  confirme: "Sait que supprimer la clé de chiffrement d'un utilisateur rend ses données illisibles partout."
  senior: "Chiffre les données personnelles avec une clé par utilisateur, pour honorer le droit à l'oubli jusque dans les sauvegardes."
  lead: "L'utilise pour rendre la suppression des données personnelles vérifiable sans réécrire les sauvegardes."
---

Chaque utilisateur a sa clé ; ses données sont chiffrées avec. Pour l'effacer, on
**détruit la clé** : ses données deviennent illisibles, y compris dans les sauvegardes et
les journaux.

Une réponse au droit à l'oubli quand réécrire les sauvegardes est impossible.
